```cpp
// button_led_sequence: each button press advances a 4-LED sequence (only one LED lit at a time).
// Adapted from https://github.com/rajeshThakare/Arduino-UNO-for-Absolute-Beginners (Codes/3_Switch/switch_practical_3, MIT).
#ifndef LOGIC_H
#define LOGIC_H
#include <Arduino.h>

#define SEQ_PIN_BUTTON 2      // INPUT with external pull-down: HIGH = pressed
#define SEQ_NUM_LEDS 4
extern const uint8_t SEQ_PINS[SEQ_NUM_LEDS];   // {7, 6, 5, 4}

void seq_init();                  // pins configured, all LEDs off, count 0
void seq_all_off();               // all LEDs LOW (count unchanged, current LED -1)
bool seq_apply(uint8_t step);     // LED[step] on and the previous LED off; false if step out of range
void seq_advance();               // apply current count, then count = (count + 1) % 4
uint8_t seq_count();              // index of the step that the next advance will apply (0..3)
int8_t seq_current_led();         // index of the LED currently lit, -1 if none
bool seq_button_pressed();        // digitalRead(SEQ_PIN_BUTTON) == HIGH
void seq_poll();                  // advance once if the button is pressed

#endif
```

### logic.cpp
```cpp
#include "logic.h"

const uint8_t SEQ_PINS[SEQ_NUM_LEDS] = {7, 6, 5, 4};

static uint8_t g_count = 0;
static int8_t g_current = -1;

void seq_init() {
  for (uint8_t i = 0; i < SEQ_NUM_LEDS; i++) {
    pinMode(SEQ_PINS[i], OUTPUT);
  }
  pinMode(SEQ_PIN_BUTTON, INPUT);
  g_count = 0;
  seq_all_off();
}

void seq_all_off() {
  for (uint8_t i = 0; i < SEQ_NUM_LEDS; i++) {
    digitalWrite(SEQ_PINS[i], LOW);
  }
  g_current = -1;
}

bool seq_apply(uint8_t step) {
  if (step >= SEQ_NUM_LEDS) {
    return false;
  }
  uint8_t previous = (step + SEQ_NUM_LEDS - 1) % SEQ_NUM_LEDS;
  digitalWrite(SEQ_PINS[previous], LOW);
  digitalWrite(SEQ_PINS[step], HIGH);
  g_current = (int8_t)step;
  return true;
}

void seq_advance() {
  seq_apply(g_count);
  g_count = (g_count + 1) % SEQ_NUM_LEDS;
}

uint8_t seq_count() {
  return g_count;
}

int8_t seq_current_led() {
  return g_current;
}

bool seq_button_pressed() {
  return digitalRead(SEQ_PIN_BUTTON) == HIGH;
}

void seq_poll() {
  if (seq_button_pressed()) {
    seq_advance();
  }
}
```

## Covering a function
- Call the module's init function at the start of every test so that tests do not depend on each other.
- For every output a function drives, assert each pin it should set and each pin it should leave unchanged.
- For functions with an index or a range argument (LED number, state number), test the first value, the last
  value and one value outside the range.

[kb/guides/testing_digital_pins.md]
Testing digital pins on the Arduino Uno / Pin numbers on the Uno

## Pin numbers on the Uno
- Digital pins 0 to 13. The analog inputs A0 to A5 are also digital pins 14 to 19.
- Pins 0 and 1 are the Serial RX/TX lines; the test protocol uses Serial, so tests must not drive them.
- PWM pins: 3, 5, 6, 9, 10, 11. `LED_BUILTIN` is pin 13.
- Check outputs against the pin numbers in the module's specification (its pin table), not against constants
  taken from the code under test: a wrong pin number in the code is only detected if the test uses the pin
  number the hardware is actually wired to.

# How to Wire and Program a Button

Pushbuttons or switches connect two points in a circuit when you press them.  This example turns on the built-in LED on pin 13 when you press the button.

### Hardware

- [Arduino Board](https://store.arduino.cc/collections/boards-modules)

- Momentary button or Switch

- 10K ohm resistor

- hook-up wires

- breadboard

[kb/examples/Button.md]
How to Wire and Program a Button / Circuit

### Circuit

Connect three wires to the board. The first two, red and black, connect to the two long vertical rows on the side of the breadboard to provide access to the 5 volt supply and ground. The third wire goes from digital pin 2 to one leg of the pushbutton.  That same leg of the button connects through a pull-down resistor (here 10K ohm) to ground. The other leg of the button connects to the 5 volt supply.

When the pushbutton is open (unpressed) there is no connection between the two legs of the pushbutton, so the pin is connected to ground (through the pull-down resistor) and we read a LOW.  When the button is closed (pressed), it makes a connection between its two legs, connecting the pin to 5 volts, so that we read a HIGH.

You can also wire this circuit the opposite way, with a pullup resistor keeping the input HIGH, and going LOW when the button is pressed.  If so, the behavior of the sketch will be reversed, with the LED normally on and turning off when you press the button.

If you disconnect the digital I/O pin from everything, the LED may blink erratically.  This is because the input is "floating" - that is, it will randomly return either HIGH or LOW.  That's why you need a pull-up or pull-down resistor in the circuit.
