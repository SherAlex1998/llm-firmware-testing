The pilot checks the infrastructure, cost and Wokwi usage. Each model × RAG pair has only 3 runs here, so these data support no conclusions about the effect of RAG or about model differences — they are descriptive only.

Each cell is one run. Blue tests passed on the original (correct) module and were run against 10 mutants; for yellow ones the failing tests were disabled and the rest (the "pruned test") was run against the mutants as well.

Terra passed on the original in all 6 runs, Sonnet in 4, Haiku in none; with the pruned test, almost every compiled test has a mutation score.

In experiment 2 the model decides how many tests to write. Haiku writes the most (19–32) and almost all of them are correct, but one wrong test is enough for a fail.

Which mutants (injected bugs) each test catches. pomodoro_rtc is hard: 8 of 10 mutants were killed by no test.

Sonnet accounts for 75% of the pilot cost; the most expensive run was cut off by the 16,000-token limit twice. The limit is raised to 32,000 for the main run.
